* DB Session là gì : 
Trong SQLAlchemy, “session” là một đối tượng trung gian giữa code Python và database.

Nó giống như:

một “phiên làm việc” với database : insert, delete,select,...
và chỉ khi bạn commit thì các thay đổi mới thật sự ghi xuống DB  

+ Mỗi 1 request (có thể gồm nhiều querry )sẽ sử dụng 1 Session 
riêng để giao tiếp với DB
